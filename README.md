Facebook Live K-Means Clustering

## 📌 Project Overview
Facebook Live K-Means Clustering is a Machine Learning project that uses the **K-Means Clustering algorithm** to group Facebook Live posts based on their engagement and interaction patterns.

## 🎯 Objective
The main objective of this project is to identify groups of Facebook Live posts with similar engagement behavior and understand different audience interaction patterns.

## 🛠️ Technologies Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 🤖 Machine Learning Algorithm
### K-Means Clustering
K-Means is an **unsupervised machine learning algorithm** that divides data into a predefined number of clusters based on similarity.
In this project, Facebook Live posts are grouped into different clusters according to their engagement-related features.

## 📊 Dataset
The project uses the **Facebook Live Sellers in Thailand** dataset.

The dataset contains information related to Facebook Live posts and their engagement activities, such as:

* Reactions
* Comments
* Shares
* Likes
* Other engagement-related attributes

## 🔄 Project Workflow
1. Import the required libraries
2. Load the dataset
3. Explore and understand the data
4. Perform data preprocessing
5. Select relevant features
6. Apply K-Means Clustering
7. Determine the optimal number of clusters
8. Visualize the clusters
9. Analyze the clustering results

## 📈 Results
The K-Means algorithm successfully groups Facebook Live posts into clusters with similar engagement characteristics. These clusters can help understand audience behavior and identify different levels of post engagement.
